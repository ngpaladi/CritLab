CritLab never receives your API key

There is no CritLab server. This is a static page: the only place your key is ever sent is intervals.icu itself, directly from your browser, in the request that fetches your rides. It is not transmitted anywhere else, not to us, and not to any third party — there is nowhere for it to go.

It is kept in this browser's storage so you don't have to paste it every visit. You can make that last only until you close the tab, or remove it entirely, below.

Generate a key under Settings → Developer on intervals.icu. It only ever grants access to your own account, and you can revoke it there at any time.

Weather

Historical conditions come from Open-Meteo (keyless, no account). CritLab sends only the race's rounded coordinates and date.

Map

The circuit map can draw roads and buildings from OpenStreetMap underneath your track, fetched once per circuit and cached in this browser. Only the bounding box of the ride is sent.

How you record

Things only you know, which no amount of signal processing can work out from the file.

Nothing is ever trimmed from the front of a race, and the start/finish line is taken to be where the recording begins.

Trims the laps after the racing without asking each time. Any race can still be put back to the full recording afterwards.

Stored data

Races are kept in this browser's IndexedDB. Nothing is uploaded anywhere.
