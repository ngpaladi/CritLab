{{ site.title }} never receives your API key

There is no {{ site.title }} server. This is a static page: the only place your key is ever sent is intervals.icu itself, directly from your browser, in the request that fetches your rides. It is not transmitted anywhere else — there is nowhere for it to go.

It is kept in this browser's storage, in the slot CritLab and CrossLab share — connect in either and both have it. The key only grants access to your own account, and you can revoke it on intervals.icu at any time.
